==========================================
HOW TO USE IT
==========================================

STEP 1: Click "✚ New Lesson Note" button

STEP 2: Fill in all fields:
  - Select Subject
  - Select Class
  - Enter Topic
  - Enter Content Summary

STEP 3: Select File (OPTIONAL)
  - Click the file input field
  - Choose a file from your computer
  - Supported: PDF, DOC, DOCX, PPTX, TXT, XLSX
  - See filename appear in green box

STEP 4: Submit
  - Click "💾 Create Lesson Note" button
  - File uploads to storage
  - Lesson note created

STEP 5: Verify
  - Go back to lesson notes list
  - You should see: 📎 File: lesson.pdf
  - Shows file was uploaded!

==========================================
TROUBLESHOOTING
==========================================

IF YOU STILL DON'T SEE IT:

1. Restart Dev Server
   - Press Ctrl+C in terminal (stop current server)
   - Run: npm run dev

2. Hard Refresh Browser
   - Press Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)

3. Clear Cache
   - Press Ctrl+Shift+Delete
   - Clear "Cached images and files"
   - Refresh page

4. Check Console Errors
   - Press F12 (open Developer Tools)
   - Go to Console tab
   - Look for red error messages
   - Report them
