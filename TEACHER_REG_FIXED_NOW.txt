HOW TO USE (Step-by-Step):
═══════════════════════════════════════════════════════════════

1. GO TO: http://localhost:3000/school-admin/dashboard

2. CLICK: "Register New Teacher" button

3. STEP 1: Select Level
   - Choose: PRIMARY or SECONDARY
   - Click: Continue →

4. STEP 2: Personal Information + Photo
   - Name: Enter teacher name
   - Email: Enter teacher email
   - DOB: Select date of birth
   - **PHOTO: Select photo file** (automatic upload!)
   - Password: Enter password
   - Confirm: Repeat password
   - Click: Continue →

5. STEP 3: Bank & Salary
   - Bank Name: e.g., "First Bank"
   - Account Number: 10-digit number
   - Salary: Monthly amount
   - Click: Continue →

6. STEP 4: Teaching Assignment
   - CLASS DROPDOWN: ✅ NOW SHOWS CLASSES
     └─ Select any class
   - SUBJECTS DROPDOWN: ✅ NOW SHOWS SUBJECTS
     └─ Select at least 3 subjects
   - Click: Complete Registration

7. SUCCESS! ✅
   - Message: "Teacher registered successfully!"
   - Photo: Uploaded automatically
   - Dashboard: Teacher appears in list
