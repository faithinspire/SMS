================================================================================
                          ROOT CAUSE ANALYSIS
================================================================================

ISSUE #1: BROADCASTS NOT REACHING STAFF
Root Cause: Migration 081 dropped broadcast_recipients table
- API endpoints expected broadcast_recipients (with proper UUID FKs)
- Migration 081 created broadcast_notifications instead (wrong schema)
- BroadcastInbox component couldn't find recipients
- Staff never received messages sent by school admin

ISSUE #2: CBT SCORES NOT POPULATING
Root Causes:
1. Submission endpoint never set status='GRADED' after scoring
2. Migration 126 trigger condition checks status='GRADED' → always false
3. Trigger never fired → score_sheets never populated
4. Historical data not backfilled
