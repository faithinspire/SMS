KEY DIFFERENCE SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BEFORE:
  1. Create School FIRST
  2. Try to Create Auth User (fails silently)
  3. Return success
  → School exists but Auth user doesn't
  → Login fails immediately

AFTER:
  1. Create Auth User FIRST (with retries)
  2. Create School
  3. Link them together
  → Both exist and are consistent
  → Login works immediately

The KEY: Auth user is created BEFORE school, not after!

RETRY LOGIC ILLUSTRATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Network Request with Retry:

┌─────────────────────────────────────────────────────────────────────────┐
│ Attempt 1: Immediate                                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ Send request                                                             │
│ ├─ Timeout / Network Error ❌                                          │
│ └─ → Retry                                                              │
│                                                                          │
│ Wait: 1 second ⏱                                                        │
│                                                                          │
│ Attempt 2: After 1 second                                               │
├─────────────────────────────────────────────────────────────────────────┤
│ Send request                                                             │
│ ├─ Success ✅ → Continue                                               │
│ ├─ Timeout / Network Error ❌ → Retry                                  │
│ └─ 4xx Error ❌ → Fail immediately (don't retry)                      │
│                                                                          │
│ Wait: 2 seconds ⏱                                                       │
│                                                                          │
│ Attempt 3: After 2 seconds                                              │
├─────────────────────────────────────────────────────────────────────────┤
│ Send request (last attempt)                                              │
│ ├─ Success ✅ → Continue                                               │
│ └─ Any Error ❌ → Return error, don't retry again                      │
└─────────────────────────────────────────────────────────────────────────┘

Result:
  • Temporary network issues don't break registration
  • Exponential backoff prevents hammering API
  • Permanent errors fail fast (no wasted retries)
  • Gives API time to recover from glitches
