DEVELOPMENT:

  curl -X POST "http://localhost:3000/api/debug/insert-test-data" \
    -H "Content-Type: application/json" \
    -d '{"action": "populate"}'

CHECK STATUS:
  curl "http://localhost:3000/api/debug/insert-test-data"

PRODUCTION (Node Script):
  node run-migration-171.js

PRODUCTION (Supabase SQL):
  1. Supabase Dashboard → SQL Editor
  2. Paste: database/migrations/171_populate_score_sheets_test_data.sql
  3. Run

PRODUCTION (API):
  curl -X POST "https://your-domain.vercel.app/api/debug/insert-test-data" \
    -H "Content-Type: application/json" \
    -d '{"action": "populate"}'

CLEAR SCORES (if needed):
  curl -X POST "http://localhost:3000/api/debug/insert-test-data" \
    -H "Content-Type: application/json" \
    -d '{"action": "clear"}'

================================================================================
API ENDPOINT RESPONSES
================================================================================

GET /api/debug/insert-test-data
Response:
{
  "debug": true,
  "totalScoreRecords": 240,        ← Number of score records in database
  "sampleData": [...],              ← 5 sample score records
  "message": "Database has 240 score records"
}

POST /api/debug/insert-test-data (action: "populate")
Response:
{
  "success": true,
  "message": "Score data populated successfully",
  "school": "School Name",
  "studentsProcessed": 10,          ← Number of test students
  "termsProcessed": 3,              ← Number of terms
  "subjectsPerStudent": 8,          ← Subjects per student
  "recordsGenerated": 240,          ← Total score records created
  "recordsInDatabase": 240          ← Verification count
}

================================================================================
DATA GENERATED
================================================================================

- School: First active school
- Students: 10 active students
- Terms: 3 (First, Second, Third)
- Subjects: ~8 per student (from actual enrollment)
- Total Records: 240 (10 × 3 × 8)

Scores per record:
  - test1: 0-10 (random)
  - test2: 0-10 (random)
  - test3: 0-10 (random)
  - test4: 0-10 (random)
  - exam: 0-60 (random)
  - total: auto-calculated (max 100)

================================================================================
TROUBLESHOOTING
================================================================================

"totalScoreRecords": 0
  → Population hasn't run yet
  → Execute: curl -X POST .../api/debug/insert-test-data -d {"action":"populate"}

"No active schools found"
  → School must have status = 'ACTIVE' in database

"No active students found"
  → Register students and mark as 'ACTIVE'

Scores not showing in UI
  → Check browser console (F12) for errors
  → Refresh page (Ctrl+F5)
  → Verify student is in selected class
