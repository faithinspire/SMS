IF SOMETHING GOES WRONG:
────────────────────────────────────────────────────────────────────────────

Error: "fatal: not a git repository"
  → You're in wrong directory
  → Change to: cd c:\Users\OLU\Desktop\SMS

Error: "nothing to commit"
  → Files might already be staged
  → Try just: git push origin main

Error: "Your branch is ahead of origin/main"
  → This is good! Just means you're ready to push
  → Run: git push origin main

Error: "Permission denied" or "Authentication failed"
  → Git credentials issue
  → Try: git config --global user.name "Your Name"
  → Then: git config --global user.email "your@email.com"
