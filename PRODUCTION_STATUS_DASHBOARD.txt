Time to Execute: 30 seconds - 1 minute

What it does:
  1. Drops old broadcasts table (wrong schema)
  2. Creates new broadcasts table with correct columns:
     - id (UUID)
     - school_id (UUID FK → schools)
     - sender_id (UUID FK → users)
     - message (TEXT)
     - broadcast_type (VARCHAR)
     - created_at, updated_at (TIMESTAMP)

  3. Creates broadcast_recipients table:
     - id (UUID)
     - broadcast_id (UUID FK → broadcasts)
     - user_id (UUID FK → users)
     - is_read (BOOLEAN)
     - read_at (TIMESTAMP)
     - UNIQUE constraint on (broadcast_id, user_id)

  4. Creates send_broadcast_to_staff() function

  5. Drops obsolete broadcast_notifications table

Expected Result:
  - broadcasts table: 1 record
