FILE MODIFIED:

FUNCTIONS ADDED:

1. generateLetterForStaff(member)
   - Takes staff member object
   - Calls POST /api/school-admin/staff/appointment-letter
   - Creates Blob from response HTML
   - Triggers automatic download
   - File saved as: [Name]_appointment_letter.html

2. generateLetterForStudent(student)
   - Takes student object
   - Calls POST /api/school-admin/students/admission-letter
   - Creates Blob from response HTML
   - Triggers automatic download
   - File saved as: [Name]_admission_letter.html

3. deleteStaff(staffId)
   - Takes staff ID
   - Shows confirmation dialog
   - If confirmed, calls Supabase delete
   - Updates state to remove staff from list
   - Shows success message

4. deleteStudent(studentId)
   - Takes student ID
   - Shows confirmation dialog
   - If confirmed, calls Supabase delete
   - Updates state to remove student from list
   - Shows success message

5. loadResultsClasses(schoolId, termId)
   - Calls POST /api/results/school-classes-and-students
   - Loads classes for selected term
   - Sets classes in state
   - Auto-selects first class

================================================================================
API INTEGRATION
================================================================================

ENDPOINTS USED:
1. POST /api/admin/dashboard-data
   Purpose: Fetch staff, students, results, transactions
   Used by: Overview, Staff, Students, Fees tabs

2. POST /api/results/school-classes-and-students
   Purpose: Get classes and students for selected term
   Used by: Results tab filtering

3. POST /api/school-admin/staff/appointment-letter
   Purpose: Generate appointment letter HTML for staff
   Used by: Staff tab letter button

4. POST /api/school-admin/students/admission-letter
   Purpose: Generate admission letter HTML for students
   Used by: Students tab letter button

5. POST /api/broadcasts/send-to-recipients
   Purpose: Send broadcast message to school members
   Used by: Broadcast tab

DATABASE QUERIES (Supabase):
1. academic_sessions table
   - Select all sessions
   - Order by session_year DESC

2. terms table
   - Select all terms
   - Order by term_number ASC

3. class_arm_combos table
   - Select all classes
   - Order by class_name ASC

4. users table (delete)
   - Delete staff member by ID
   - Delete student by ID
