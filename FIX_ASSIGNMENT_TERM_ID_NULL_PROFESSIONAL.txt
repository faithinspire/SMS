================================================================================
        FIX: ASSIGNMENT - NULL VALUE IN COLUMN TERM_ID
================================================================================

ERROR:
  "Failed to create assignment: null value in column 'term_id' 
   of relation 'assignments' violates not-null constraint"

ROOT CAUSE ANALYSIS:
  1. assignments table has term_id column with NOT NULL constraint
  2. Code does NOT include term_id in insert (correct behavior)
  3. When term_id is omitted, it defaults to NULL
  4. NULL violates NOT NULL constraint → ERROR

✅ PROFESSIONAL SOLUTION:
  Make term_id OPTIONAL in database so teachers don't need to select term
  This is consistent with lesson_notes fix (migration 099)

================================================================================
                    TECHNICAL EXPLANATION
================================================================================

WHY THIS HAPPENED:

1. Database Schema:
   CREATE TABLE assignments (
     ...
     term_id UUID NOT NULL,  ← ❌ Cannot be NULL
     ...
   )

2. Application Code:
   const insertData = {
     school_id: ...,
     teacher_id: ...,
     subject_id: ...,
     // term_id NOT INCLUDED (omitted on purpose)
   }
   
   When term_id is not included, Supabase sets it to NULL
   NULL violates NOT NULL constraint → ERROR

3. Solution:
   ALTER TABLE assignments 
     ALTER COLUMN term_id DROP NOT NULL;
   
   Now term_id can be NULL, so omitting it works fine

================================================================================
                    DESIGN DECISION
================================================================================

Why Make term_id Optional?

1. WORKFLOW: Teachers create assignments first, term assignment comes later
   - Teacher: "I'm assigning work for my Math class"
   - Later: Admin maps assignment to academic term
   
2. FLEXIBILITY: Not all assignments need terms
   - Projects and homework may span multiple terms
   - Some assignments are general/ongoing

3. CONSISTENCY: Matches lesson_notes table
   - lesson_notes also has optional term_id (migration 099)
   - Both are teaching materials
   - Both benefit from optional term assignment

4. USER EXPERIENCE: No extra friction
   - Teachers don't need to know current term
   - Term can be assigned during review/approval
   - Faster creation workflow
