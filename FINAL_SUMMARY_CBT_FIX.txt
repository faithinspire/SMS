================================================================================
                          TROUBLESHOOTING
================================================================================

Q: Migration fails to execute
A: Check if all required tables exist. Review error message. Tables needed:
   cbt_submissions, cbt_exams, score_sheets, students, academic_terms, academic_sessions

Q: Trigger doesn't fire for new submissions
A: Verify:
   1. Trigger exists: SELECT * FROM information_schema.triggers WHERE trigger_name LIKE '%auto_populate%'
   2. Exam has subject_id: SELECT subject_id FROM cbt_exams
   3. Student has class: SELECT class_arm_combo_id FROM students
   4. Submission has term_id: SELECT term_id FROM cbt_submissions

Q: Score doesn't appear after submission
A: Check:
   1. score_sheets has entry: SELECT * FROM score_sheets WHERE exam_source = 'CBT' LIMIT 1
   2. Student enrolled: SELECT * FROM student_subjects WHERE student_id = [id]
   3. Academic session linked: SELECT academic_session_id FROM score_sheets

Q: Wrong score values showing
A: Verify:
   1. Exam total_marks: SELECT total_marks FROM cbt_exams
   2. Assessment type: SELECT assessment_type FROM cbt_exams
   3. Calculate expected: (raw_score / total_marks) * column_max

See 00_CBT_RESULTS_FIX_COMPLETE.md for more troubleshooting steps.
