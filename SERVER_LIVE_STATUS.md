## 🎯 QUICK START - Phone Access

### 3 Steps:

1. **Get IP**
   ```
   Windows Key + R → cmd → ipconfig
   Find: IPv4 Address (e.g., 192.168.1.105)
   ```

2. **Connect Phone to Same WiFi**
   - Phone WiFi = Computer WiFi
   - Names must match

3. **Open Phone Browser**
   ```
   http://192.168.1.105:3000
   (Replace IP with your actual IP)
   ```

**That's it! App loads on phone! 🎉**
