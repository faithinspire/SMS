## FEATURE 1: Set Up Your School Information

### Step 1: Access School Settings
1. Log in to School Admin Dashboard
2. Look for **⚙️ Settings** button (top area)
3. Click it to open **School Settings & Code of Conduct** modal

### Step 2: Enter School Motto
1. Go to **📋 General Info** tab
2. Enter your school motto (e.g., "Excellence, Integrity, Service")
3. This will appear in all staff appointment letters

### Step 3: Enter Vision & Mission
1. Go to **🎯 Vision & Mission** tab
2. Enter your school's **Vision Statement** (e.g., "To produce morally upright, academically excellent graduates...")
3. Enter your school's **Mission Statement** (e.g., "To provide quality education in a conducive environment...")
4. These will appear in all student admission letters

### Step 4: Set Code of Conduct
1. Go to **📘 Code of Conduct** tab
2. Enter **Code of Conduct URL** (optional - link to external document)
3. Enter **Code of Conduct Key Points** - Format as numbered list:
   ```
   1. Students must wear complete school uniform
   2. Mobile phones are not allowed in class
   3. Respect for staff and fellow students is mandatory
   4. Academic integrity: No cheating or plagiarism
   5. Violence or bullying will result in suspension
   6. Punctuality and regular attendance are required
   ```
4. Click **💾 Save Settings** ✅

✅ Each staff member role now gets a customized letter

1. Go to **👨‍🏫 Staff & Teachers** tab
2. Find the staff member

- ✅ Position-specific benefits
- ✅ Working hours for that role

- ✅ School motto

## FEATURE 4: Manage Staff Passwords

### When You Need This
- ✅ New staff joined - generate temporary password
- ✅ Staff forgot password - reset with temporary
- ✅ Staff left - automatic access removal logged
- ✅ Audit trail - track all password changes

### How to Access
1. Go to **School Admin Dashboard**
2. Look for **🔐 Password Management** button
3. Click it to open staff password management modal

### Generate Temporary Password
1. Find staff member in list
2. Click **🔄 Reset** button
3. System generates random 12-character password
4. **💡 Important**: Password is shown ONCE - copy immediately!
5. Click **📋 Copy** to copy to clipboard
6. Click **👁️ Show/Hide** to view password
7. Share password with staff member
8. **Note**: Staff MUST change password on first login (forced)

### View Password Change History
1. Find staff member in list
2. Click **📋 History** button
3. See all password changes:
   - Date & time changed
   - Reason for change
   - Who made the change
   - Whether forced change required
4. Click **Back** to return to staff list

### Staff Status Indicators
- 🟢 **✅ Active** - Password OK, no change needed
- 🟠 **⚠️ Requires Change** - Staff must change password on next login
- 🔴 **Access Revoked** - Staff removed from system

### Automatic Logging
When staff member is removed from system:
- ✅ Access automatically revoked
- ✅ Password change logged in history
- ✅ Timestamp recorded
- ✅ Reason: "Staff removed from system"

## ❓ FAQ

### Q: Can I edit generated letters?
**A:** Letters are read-only in modal, but you can:
- Copy to Word and edit manually
- Share raw text and edit externally
- Modify underlying school settings for consistency

### Q: What if I generate wrong letter?
**A:** No problem! Letters are not automatically saved. Just:
1. Close modal
2. Click Letter again
3. Generate correct version

### Q: Where are passwords stored?
**A:** 
- Passwords: Secure Supabase Auth (encrypted)
- Change history: staff_password_history table (audit trail)
- Never stored in plain text

### Q: Can I bulk generate letters?
**A:** Currently one-by-one, but plan for bulk in future

### Q: How do I know if settings were saved?
**A:** Green success message appears at top of modal after saving

### Q: Can parent see admission letter?
**A:** Yes! Share via:
- WhatsApp (enter parent phone)
- Email (enter parent email)
- Download and print
- Print directly from browser

### Q: What if class teacher not showing?
**A:** Make sure:
1. Student is assigned to a class (class_arm_combo_id set)
2. Class has a class teacher assigned
3. Regenerate letter

### Q: Can I change password for staff?
**A:** Yes via 🔐 Password Management → Reset button

## 🔧 TROUBLESHOOTING

### Settings Not Saving
1. Check internet connection
2. Try again
3. Check browser console for errors
4. Contact IT support

### Letter Not Showing Class Teacher
1. Check student is in a class
2. Check class has class teacher assigned
3. Try regenerating letter
4. Check database query: `SELECT class_teacher_id FROM class_arm_combos WHERE id = [class_id]`

### Password Not Generating
1. Refresh page
2. Ensure Migration 033 executed
3. Check staff member exists
4. Try different staff member
5. Check school_id is correct

### Position Details Missing from Letter
1. Check Migration 033 created position_details table
2. Check school has position records
3. Try regenerating letter
4. Manually populate position_details if needed
