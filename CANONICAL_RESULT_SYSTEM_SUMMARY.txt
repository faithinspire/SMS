IMPLEMENTATION OVERVIEW
================================================================================

The canonical result system aggregates all result sources (manual teacher scores,
CBT tests, CBT exams, student submissions) into a single source of truth with
role-based APIs for Teachers, School Admins, Principals, and Students.

DATA FLOW:
  Teacher → Score Sheets / CBT → CanonicalResultService →
  Role-Based APIs → School Admin / Principal / Student Pages

================================================================================
DATA STRUCTURE: CanonicalResult
================================================================================

{
  id: string;
  school_id: string;
  student_id: string;
  subject_id: string;
  session_id: string;
  term_id: string;
  
  // Component scores
  test_scores: { test1?, test2?, test3?, test4?, total_tests? };
  exam_score?: number;
  cbt_test_score?: number;
  cbt_exam_score?: number;
  
  // Aggregated totals
  manual_total: number;      // Tests + Exam
  cbt_total: number;         // CBT Tests + CBT Exam
  overall_total: number;     // Manual + CBT combined
  
  // Grade & remark
  grade: string;             // A, B, C, D, E, F, N/A
  remark: string;            // Excellent, Very Good, Good, Fair, Pass, Fail
  
  // Metadata
  created_at: string;
  updated_at: string;
  source: 'manual' | 'cbt' | 'hybrid';
}

================================================================================
AGGREGATION FORMULAS
================================================================================

MANUAL TOTAL = Test1 + Test2 + Test3 + Test4 + Exam

CBT TOTAL = Σ(CBT Test Scores) + Σ(CBT Exam Scores)

OVERALL TOTAL = MANUAL TOTAL + CBT TOTAL

GRADE SCALE:
  80-100  → A (Excellent)
  70-79   → B (Very Good)
  60-69   → C (Good)
  50-59   → D (Fair)
  40-49   → E (Pass)
  0-39    → F (Fail)
  0       → N/A (Not Graded)
