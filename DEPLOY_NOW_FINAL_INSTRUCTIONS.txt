================================================================================
IF SOMETHING GOES WRONG
================================================================================

Common issues:

1. "git command not found"
   → Git not installed. Install from https://git-scm.com/

2. "Authentication failed"
   → GitHub credentials not cached
   → Open GitHub Desktop instead (see Option 2 below)

3. "Push rejected"
   → Check you have push access
   → Try GitHub Desktop instead

Alternative deployment methods:

OPTION 2 - GitHub Desktop:
  1. Open GitHub Desktop
  2. Select SMS repository
  3. Click "Commit to main"
  4. Click "Push origin"
  5. Done!

OPTION 3 - GitHub Web:
  1. Go to https://github.com/faithinspire/SMS
  2. Click "Actions" tab
  3. Latest workflow will trigger deployment
