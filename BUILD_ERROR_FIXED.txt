ERROR FOUND:
"Error: supabaseKey is required" during Vercel build

ROOT CAUSE:
Supabase client was being instantiated at module load time (before environment variables available)

FIX APPLIED:
Moved Supabase client creation to lazy-load inside the POST function

COMMIT: 0307049
MESSAGE: "FIX: Move Supabase client to lazy-load inside function to avoid build-time errors"

================================================================================
WHAT CHANGED
================================================================================

File: src/app/api/broadcasts/send-to-recipients/route.ts

BEFORE (Build Error):
```typescript
const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
)
```

AFTER (Build Success):
```typescript
function getSupabaseClient() {
  return createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.SUPABASE_SERVICE_ROLE_KEY!
  )
}

export async function POST(request: NextRequest) {
  const supabase = getSupabaseClient()
  // ... rest of function
}
```

RESULT: ✅ Client only created when request arrives (env vars available)
